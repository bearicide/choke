# CHOKE Audio Packs

Each folder inside `/assets/audio/packs/` is treated as a live CHOKE sound bank.

## Recommended Structure

```text
assets/audio/packs/
  cyberpilot/
  deep-dark-pit/
  friday/
  low/
  machine/
  machine-demo/
  transitions5/
```

## Standard Stem Layout

```text
0 Drums.mp3
1 Bass.mp3
2 Percussion.mp3
3 Synth.mp3
4 Other.mp3
```

## Engine Behavior

- Auto-detect packs
- Auto-map pads
- Global choke support
- Quantized playback
- Dynamic loading
- Mobile-safe preload behavior
- Future drag/drop compatible

CHOKE is designed as a performance-first stem weapon.
