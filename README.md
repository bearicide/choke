# CHOKE — BY MATTBEAR

CHOKE is a neon-industrial live performance machine for instant loop control, auto-chopping, glitch remixing, and aggressive real-time audio manipulation.

## Put this in GitHub

Recommended repo/path:

```text

```

Live URL after GitHub Pages updates:

```text

```

## Quick Start

1. Open `index.html` in Chrome, Edge, or another modern Chromium browser.
2. Tap/click **START AUDIO**.
3. Use the 16 pads.
4. Import an MP3/WAV/OGG/M4A file to auto-chop slices onto pads.
5. Use **SPACE** for Master Choke and **TAB** for Resync.

## Controls

### Pad Controls

Each pad has four big controls:

- **ON** — launch once, quantized
- **LOOP** — toggle synced loop
- **TEST** — preview without changing loop state
- **OFF** — stop that pad on-grid

### Keyboard Map

```text
Q W E R
A S D F
Z X C V
1 2 3 4
```

Global controls:

```text
SPACE = MASTER CHOKE
TAB = HARD RESYNC
CTRL + SHIFT + A = ADMIN PANEL
H = HELP
I = IMPORT
```

### Mouse

- Left click/tap = normal action
- Right click on a pad = TEST
- Wheel over a pad = quick volume change

### Touch

CHOKE is touch-first:

- multi-touch safe
- no double-tap zoom
- no accidental scroll on controls
- big hit targets
- vibration feedback where supported

## Timing

Everything is quantized. No free timing mode.

Launch/stop timing options:

```text
1/32, 1/16, 1/8, 1/4, 1/2, 1 BAR, 2 BAR, 4 BAR, 8 BAR,
1/16T, 1/8T, 3/16, 5/16, 7/16, 5/8, 7/8, 9/8, 11/8, 13/8
```

## Admin Panel

Open with:

```text
CTRL + SHIFT + A
```

Admin includes:

- BPM
- swing
- visual intensity
- launch/stop quantize
- choke group mode
- diagnostics
- touch log
- kit save/load
- panic reset

## Notes

The included WMA source files are carried as source audio, but browser support for WMA decoding is inconsistent. Use the import button with MP3/WAV/OGG/M4A for best playback.

CHOKE is not a DAW. It is a one-screen performance weapon.
